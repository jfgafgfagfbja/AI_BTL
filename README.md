# AI - Bài Tập Lớn

Tập hợp các bài tập về AI: tìm kiếm, trò chơi, và machine learning.

## Cấu trúc

| File | Nội dung |
|------|----------|
| `astar_demo.py` | Demo thuật toán A* trên đồ thị |
| `bai1_best_first_search.py` | Best First Search – tìm đường bản đồ phường (Pygame) |
| `bai2_astar_puzzle.py` | A* giải bài toán 8-Puzzle (Pygame) |
| `bai3_caro.py` | Game Caro (Gomoku) – Người vs Máy Minimax (Pygame) |
| `bai4_co_vua.py` | Game Cờ Vua – Người vs Máy Minimax + Alpha-Beta (Pygame) |
| `bai5_co_tuong.py` | Game Cờ Tướng (Xiangqi) – Người vs Máy (Pygame) |
| `bai6_kmeans.py` | Thuật toán K-Means clustering có animation |
| `classification_metrics.py` | Tính các metric phân loại (Confusion Matrix, ROC, AUC) |
| `heart_analysis.py` | Phân tích bệnh tim với Logistic Regression, RF, SVM |

## Cài đặt

```bash
pip install -r requirements.txt
```

Cho các bài Pygame:
```bash
pip install pygame
```
